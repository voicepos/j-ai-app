📖 Hướng dẫn cài đặt từng bước
Bước 1: Đăng ký tài khoản tại twilio.com
Bước 2: Mua một số điện thoại (Phone Numbers → Buy a number)
Bước 3: Deploy server backend (xem thư mục /server trong source code)
  → Khuyến nghị: Railway.app (free tier có sẵn)
Bước 4: Nhập URL server vào ô "URL Server Backend" ở trên
Bước 5: Copy webhook URLs và dán vào Twilio Console → Phone Numbers → [số của bạn]
Bước 6: Nhập Account SID & Auth Token → Lưu
Bước 7: Gọi thử đến số Twilio và nói chuyện với J-AI! 🎉
